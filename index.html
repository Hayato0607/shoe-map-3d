    ブランドを管理

    色はグラフ上のカードの縁と絞り込みに使われます。名前と色は変えるとすぐに反映されます。カードが登録されているブランドは削除できません。

      データを書き出す

      ブランドとカードの全データ（JSON）です。バックアップや、別のサイトに移すときに使えます。

      操作方法

      グラフを動かす（マウス）

      ホイール
      左右に回転
      Shift＋ホイール
      上下に傾ける（トラックパッドの横スクロールも同じ）
      ホイールクリック
      オートスクロール。クリックした位置からマウスを離した方向・距離に応じて回り続けます。もう一度クリックするか Esc で終了
      ドラッグ
      自由に回転
      Ctrl＋ホイール
      拡大・縮小（トラックパッドのピンチも同じ）
      画像にカーソルを重ねる
      シューズカードと、速さ・反発・重さ・価格・発売年の詳細を表示
      画像をクリック
      カードを表示したままにする（もう一度クリックで解除）

      グラフを動かす（スマホ・タブレット）

      スワイプ
      回転
      ピンチ
      拡大・縮小
      画像をタップ
      シューズカードと詳細を表示（もう一度タップで解除）

      キーボード（グラフをクリックしたあと）

      ← →
      左右に回転
      ↑ ↓
      上下に傾ける
      ＋ −
      拡大・縮小
      Esc
      選択の解除、オートスクロールの終了

      画面下のボタン

      3D
      立体の表示に戻す
      z = 0 ／ x = 0 ／ y = 0
      その軸の方向からまっすぐ見た平面で表示。ボタンの下に、いま表示される2つの軸が出ます
      年代で切り取る
      選んだ年代のシューズだけを表示。スライダーで年、「1年／3年／5年」で幅、▶で1年ずつ自動再生、× で終了
      − ＋
      拡大・縮小

      右側のパネル

      ブランドで絞り込み
      クリックで表示・非表示を切り替え。ダブルクリックでそのブランドだけを表示。「すべて表示」で全ブランドに戻す
      検索
      モデル名・ブランド名で一覧を絞り込み（グラフはそのまま）
      ☆ ／ 注目のみ
      一覧の☆で注目に追加。「注目のみ」を押すと、注目したシューズだけをグラフと一覧に表示
      目のボタン
      そのシューズをグラフから隠す・戻す。「すべて表示／すべて非表示」で一覧に出ているものをまとめて切り替え
      横軸・縦軸
      速さ・反発・重さ・価格から2つを選択（奥行きは年代で固定）。⇅ で入れ替え。データが空欄のシューズは、その軸ではグラフに出ません
      年代の範囲
      開始年・終了年を入力して Enter。「データに合わせる」で表示中のシューズに合わせ、「元に戻す」で 2015〜2030年に戻す
      並べ替え
      一覧の並び順を変更
      カードの大きさ
      グラフ上の画像とカードの大きさを変更
      補助線
      各シューズから床・奥の壁・横の壁へ垂線を引き、値を読み取りやすくする

      表示をそのまま共有する

      軸、年代の範囲、切り取り、隠したシューズ、注目したシューズは、ページの URL に自動で入ります。いま見ている URL をそのまま送れば、相手も同じ状態で開けます。

      編集モード（URL の末尾に ?edit）

      カードを追加 ／ 編集
      モデル名、ブランド、画像、速さ、反発、発売年、重さ、価格、メモを入力
      ブランドを管理
      ブランドの追加、名前と色の変更、カードのないブランドの削除
      data.js を書き出す
      変更をファイルにしてダウンロード。リポジトリの data.js と置き換えて push すると公開ページに反映
      下書きを破棄
      このブラウザの下書きを消して data.js の内容に戻す（反映を確認してから）
